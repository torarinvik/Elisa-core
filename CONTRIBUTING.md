# Contributing to Elisa Core

Anyone can contribute. Bug reports, examples, documentation, tests, and compiler improvements are all welcome.

LLM-assisted and fully LLM-generated contributions are welcome. You can submit them without disclosure or special approval. All contributions go through the same review.

## Submit a change

1. Open a pull request and explain what changed and why.
2. Include any checks you ran and their results. For bug fixes, a small Elisa program that reproduces the issue helps reviewers.

For compiler changes, see the [compiler guide](compiler/README.md) for build and test commands and the [repository instructions](AGENTS.md) for source-file size and rebuild timing.
