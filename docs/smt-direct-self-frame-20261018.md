# Read-only frames for direct self recursion

Whole-body read-only frame inspection now admits an exact monomorphic direct call to the same inspected declaration. The shortcut checks exact symbol identity, resolved parameter types, and declaration/FuncType generic and effect surfaces. Parameters are limited to primitive/view values and immutable nonlinear references; owning aggregates by value decline. Unknown borrowed-return metadata is allowed only for an exact builtin bool return, which cannot carry an owner/view. The general callee-frame check is unchanged. It still checks all explicit arguments and every other body operation, including operations after the self call. Variadic, forwarded and missing/defaulted arguments retain their existing rejection guards; shadowed names cannot become self calls. Mutable parameters and non-inspectable permissions still decline. Indirect/mutual recursive cycles keep the existing conservative cache guard.

This is a no-writes argument, not a termination claim: any finite execution consists of checked non-self operations and more executions of the same complete body. No self-call assumption is exported independently of that body check. The function may still fail its separate termination or functional proof obligations.

A complete implementation-scope lookup extraction uses the exact production Ast.Pos and Ast.EnumAnnotation definitions, including their source-view fields. With a checked recursive-step contract and early return, the helper's own postconditions and the runtime loop all prove. Before the frame change the same candidate reported ghost postcondition and loop-invariant failures. The original found-accumulator loop remains unproven; this result requires the coordinated early-return source candidate. No shared source was changed and no full Stage1 product is qualified.

Controls reject a later element store, an unknown/effectful argument, forwarded or missing arguments, a shadowed self name, an incorrect runtime hit, and a false recursive-step contract. The source-bound structural gate also passes in memory. The two-file production source/checker patch is retained under `build/verification/assoc-scope-step-20261018/scope-early-return.patch`; independent proof-product replay has not run.
